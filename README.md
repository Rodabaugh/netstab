# netstab

A network stability testing tool that saves timestamped network latency details to a CSV file, and preforms automatic analysis of testing results and logs. netstab is built in Python and has a GUI written in tkinter. netstab was created to be a user friendly tool that help desk engineers could use to test client networks, and to diagnose network stability issues.

# Usage

Ensure you have at least Python 3.2 installed.

Download the zip file for the repo and extract it.

Run either the .sh or .ps1 file to start the program.
